# Casting

Glint's test bench. Build: concatenate mocap.js, engine.js, mocap-char.js, rework.js, rework2.js and lab.js inside a script tag after shell.html (see CLAUDE.md). The live version is a private Claude artifact that saves Kennedy's notes; this copy is the source.

mocap.js is baked by bake.py from the CMU Graphics Lab Motion Capture Database (mocap.cs.cmu.edu; created with funding from NSF EIA-0196217), BVH conversion by B. Hahne.
