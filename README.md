# Glint

A music-visualizer design studio. Place nodes on a canvas, give each one a form and a way of traveling, blend personalities over the whole design, and watch it react to music from a demo beat, an audio file, or the microphone.

- `index.html`, `styles.css`, `app.js`: the Studio (plain static files, no build step)
- `forms.html`: the forms gallery
- `CLAUDE.md`: the full project guide and design decisions

Designs save in the browser on each device for now.
